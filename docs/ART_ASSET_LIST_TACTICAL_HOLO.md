# 战术全息科幻 · 美术资源清单

> 关联文档：`RTS_STYLE_RESEARCH.md` → 方向 A（首选）
> 视觉锚点：**指挥终端全息沙盘** —— 深色地面 + 半透明网格 + 高饱和阵营色 + 发光描边
> 目标：给「采矿 / 造工人 / 造兵 / 基地攻防」这套玩法定一份可以直接开工的画单
> 基准：1 个可玩阵营 + 1 个敌方阵营（同模型换色）+ 12 种单位 + 8 种建筑 + 1 套地形，Phaser 3 正交俯视

---

## 1. 设计目标与视觉锚点

要达成的三个观感：

1. **读图快**：0.3 秒内分清「工人 / 步兵 / 载具 / 建筑」，靠剪影差异 + 阵营色，不靠贴图精度。
2. **像全息沙盘**：暗底、发光轮廓、半透明网格、扫描线，一眼看出是「战术指挥界面」而不是「写实战场」。
3. **便宜可复用**：单位 = 同底盘换色/换炮塔；特效 = 程序化；真正要手绘的只有「剪影本体」。

视觉钩子（差异化抓手，必须贯穿始终）：**网格扫描线 + 数据流 UI**。全项目只要有这一条记忆点，就不会被说「像星际/像 BAR」。

## 2. 全局视觉规范

### 2.1 规格系统

| 项 | 值 | 说明 |
|---|---|---|
| 目标分辨率 | 1920×1080（响应式） | 以 16:9 为基准缩放 |
| 地图 tile | 64×64 px | 正交俯视，正方形网格 |
| 单位画布 | 128×128 px | 实际屏幕显示 32~72 px，预留旋转余量 |
| 建筑画布 | 192×192 px | 实际显示 96~128 px |
| 图标画布 | 64×64 px | UI 统一 |

| 发光 | 复用 1 张径向渐变 glow 贴图 | 所有发光共用，靠 tint 换色 |

| 主文字 / 次文字 | `#D7E4F5` / `#8296B5` | 白蓝 / 灰蓝 |

### 2.3 发光与描边规则

- 所有单位、建筑的**轮廓描边**统一 2px，用各自阵营主色（A 蓝 / B 橙）。
- 发光用同一张径向渐变 glow 贴图，`tint` 成阵营色，`blendMode: ADD`。
- **状态色**：己方选中 = 亮主色；受到指令 = 白/绿闪烁；被敌人选中 = 红描边。不要引入第四种无意义颜色。

### 2.4 命名规范（约定即标准）

- 单位：`unit_{类型}_{部件}`，如 `unit_worker_body`、`unit_tank_turret`。
- 建筑：`bld_{类型}`，如 `bld_base`、`bld_factory`。
- 阵营色不落在资源文件里，**由代码 tint 上色**，一套贴图两阵营复用。
- 图标：`icon_{对象}`，与单位/建筑 ID 一一对应。

## 3. 资产总览：真正要画 vs 程序化

这是小团队最该看的一张表——**真正需要绘制的资产少得出乎意料**。

| 类目 | 数量 | 是否手绘 | 说明 |
|---|---|---|---|
| 单位车身剪影 | 12 张 | ✅ 手绘 | 核心工作量，Vector/SVG |
| 单位可旋转件（炮塔/机头） | 约 7 张 | ✅ 手绘 | 供代码独立旋转 |
| 建筑本体 | 8 张 | ✅ 手绘 | 主视觉焦点，优先做 |
| 地形 tile | 12 张 | ✅ 手绘（可程序化） | 基础 + 变体 |
| 资源晶体 | 1 张 | ✅ 手绘 | 采集点 |
| glow 发光贴图 | 1 张 | ✅ 手绘 | 全项目复用 |
| UI 图标 | 约 26 个 | ✅ 手绘（矢量） | 单位 12 + 建筑 8 + 通用 6 |
| UI 面板/光标 | 约 8 张 | ✅ 手绘 | 面板框、光标组 |
| 特效（弹道/爆炸/选中框/扫描线…） | — | ❌ 程序化 | 见第 7 节 |
| 阵营 tint / 血条 / 进度环 | — | ❌ 程序化 | 代码 + glow 贴图 |

> 结论：**手绘资产 ≈ 40~50 张小图**，其余全部由 Phaser 的 `Graphics` / `Particles` / `tween` 生成。

## 7. 特效（程序化，0 手绘）

全部用 Phaser `Graphics + Particles + tween` 实现，仅复用第 2 节的 1 张 glow 贴图。

| 特效 | 实现 | 参数要点 |
|---|---|---|
| 选中框 | `Graphics` 描边圆角框 + 四角括号 | 阵营色 2px，`ADD` 混合 |
| 血条 / 护盾条 | `Graphics` 矩形 | 已方绿→阵营色渐变，受伤闪现 |
| 建造进度环 | `Graphics` 弧形 `arc` | 顺时针填充，青绿 |
| 单位移动拖尾 | `Particles` 尾迹 | 短寿命 150ms，阵营色，数量随速度 |
| 攻击弹道 | `Graphics` 线段 / `tween` | 高亮实线，命中后消散 |
| 命中闪光 | 小圆形 sprite + `add` | 1 帧缩放淡出 |
| 爆炸 | `Particles` + 冲击波圆 | 橙色 + 白心 + 扩散圆环 |
| 采集激光 | `Graphics` 直线 + 抖动 | 采集机 ↔ 晶体，青绿/阵营色 |
| 基地能量脉冲 | 圆形 `tween` 扩散 | 由主基地向外，阵营色，常驻低频 |
| 网络扫描线 | 全屏重复横线位移 | 极低透明度，贯穿全场（视觉钩子） |
| 阵亡残骸 | 剪影变暗 + 淡出 | 复用单位贴图 tint 灰，`DOOM` 缓动 |

│   ├── tile_ground.png

│   ├── icon_worker.png

约定：
1. **阵营色永不烧进贴图**，一律 `palette.json` 里的 tint 常量。
2. 所有源文件用 SVG（可改可换色），PNG 是导出产物。
3. 同类型资源尺寸、描边、发光参数保持完全一致，否则拼在一起立刻廉价。

## 11. 与 Phaser 落地对接要点

1. **开 `pixelArt: false`**（本风格是矢量流，不要像素平滑）。
2. 发光统一走 `blendMode: Phaser.BlendModes.ADD` + glow 贴图 `tint`。
3. 旋转类部件（炮塔/机头）用 `Container` 分层：`body` 在底，`turret` 在上，独立 `angle`。
4. 单位移动动画 = `tween` 缩放脉冲 + 拖尾粒子，**不做逐帧动画**。
5. 同屏 200 单位用对象池 + 网格寻路（A* 或流场），`fx` 特效全部走独立短生命周期粒子。
6. 网格线、扫描线用单张 `Graphics` 生成的 `RenderTexture` 缓存，避免每帧重画。

## 附：一句话行动清单
