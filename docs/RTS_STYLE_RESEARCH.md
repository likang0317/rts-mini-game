# 主流 RTS 风格与主题调研

> 面向项目：浏览器端 2D RTS 小游戏（Vite + TypeScript + Phaser 3）
> 目的：看清 RTS 的风格谱系，为「采矿 / 造工人 / 造兵 / 基地攻防」这套基础玩法选定主题与美术方向
> 整理时间：2026-11
> 信息边界：经典作品按公开资料核对；Stormgate、Beyond All Reason、0 A.D.、ZeroSpace 等较新/仍在变化的项目已联网核实，标注了核实时间与来源；无法确认的一律写「未核实」，不做推测性数据

---

## 1. 一句话结论

**RTS 的美术风格，本质上是「在俯视视角下，让玩家在 0.3 秒内分清敌我、兵种和资源」这件事的不同解法。**
科幻/工业题材用「几何剪影 + 阵营色 + 发光」解决，最容易用程序化和低资源量做到；历史/写实题材靠「材质和考据」解决，成本最高；末世/北欧/卡通题材靠「氛围和插画感」解决，性价比最高但对美术统一性要求高。

对一个 Phaser 2D 小项目，**主题选「科幻/工业」或「末世」的边际成本最低**，因为这两类允许大量复用同一套单位骨架（换颜色、换炮塔、换贴花），也天然容忍「几何色块」这一现状。

---

## 2. 按主题谱系的归类

RTS 的主题大致可归为 8 个谱系。下表先给结论，后面第 3 节逐个作品展开。

| 谱系 | 代表作品 | 受众感觉 | 常见美术处理 | 小团队（2D 手绘/像素）可行性 |
|---|---|---|---|---|
| A. 科幻太空歌剧 | 星际争霸 II、风暴之门、家园、ZeroSpace | 「正统、竞技、大片感」；受众最广，也最容易被拿去和 SC2 比 | 硬表面 + 强阵营色 + 发光贴图；单位剪影高度区分 | ★★★★☆ 高：几何 + 辉光即可成立，单位和建筑可模块化 |
| B. 硬科幻 / 工业机械 | 最高指挥官、Beyond All Reason | 「大场面、钢铁洪流、硬核」；受众偏核心向 | 低模金属灰 + 阵营色条；靠弹道、爆炸、尾迹撑画面 | ★★★★★ 最高：模块化履带/炮塔，2D 下几乎不需要逐帧动画 |
| C. 高奇幻 | 魔兽争霸 III、神话时代 | 「角色感、魔法、热闹」；受众广，但期待值高 | 低模大色块、夸张武器比例、暖色调、大量法术特效 | ★★★☆☆ 中：单位少但每单位要有个性，特效成本高 |
| D. 历史写实 | 帝国时代系列、0 A.D.、国家的崛起、全面战争 | 「厚重、考据、文明代入」；受众稳定且忠诚 | PBR 写实材质、建筑考据、去饱和自然色 | ★★☆☆☆ 偏低：建筑种类多、考据压力大，2D 等距建筑最费工 |
| E. 现代 / 二战军事 | 英雄连、战争黎明（暗黑科幻）、命令与征服 | 「硬派、战术、电影感」；受众偏成年男性 | 去饱和写实、泥泞脏迹、动态光照与破坏 | ★★☆☆☆ 偏低：写实纹理在 2D 俯视下很难不糊，且极易显廉价 |
| F. 末世 / 僵尸 / 蒸汽朋克 | 亿万僵尸、风暴崛起（核战后） | 「压迫、绝望、爽感」；传播性强，直播友好 | 暗棕/铜色 + 火光高对比；尸潮用深色剪影堆量 | ★★★★☆ 高：暗色调天然掩盖细节不足，剪影堆量就是效果 |
| G. 北欧 / 神话部落 | 北欧之地 | 「清冷、克制、有品」；差异化强，女性玩家比例相对高 | 扁平矢量插画 + 描边、低饱和冷色、季节变色 | ★★★★☆ 高：扁平插画风对帧数要求低，2D 反而是原生优势 |
| H. 极简 / 低多边形 / 像素 | 8-Bit Armies、Rusted Warfare、Mindustry、Tooth and Tail | 「轻量、复古、独立」；接受度取决于包装 | 像素或纯色几何、有限调色板、UI 即美术 | ★★★★★ 最高：可以先用几何色块做玩法验证，再逐批替换 |

### 2.1 几条跨题材的规律

1. **俯视角下「剪影 > 细节」。** 星际争霸 II 的单位在最低画质下依然可辨，靠的是轮廓差异（宽/窄、高/矮、有无炮管）。2D 小项目更应把预算花在剪影上，而不是贴图精度。
2. **阵营色是免费的可读性。** 所有 RTS 都用「同一模型 + 不同阵营色」解决敌我识别。这是小团队最该抄的一条。
3. **单位量级决定美术路线。** 单局 20~40 个单位（英雄连、北欧之地）可以逐个精修；单局 200+（星际 2、最高指挥官、BAR）必须走模块化、可换色、可复用的路线。
4. **暗色调比亮色调便宜。** 末世、暗黑科幻能用阴影和雾遮住大量细节缺失；明亮写实（帝国时代）没有任何遮挡空间。
5. **2D 等距 ≠ 2D 俯视。** 等距（isometric）视觉更「像老 RTS」，但寻路、深度排序、遮挡处理都要额外一层复杂度；正交俯视（top-down）实现成本约低 30%~50%。

## 3. 逐个作品拆解

### 3.1 星际争霸 II（StarCraft II，2010）

- **世界观 / 主题**：太空歌剧。人类（Terran）、虫族（Zerg）、神族（Protoss）三族在星际边缘争夺生存空间，战役带有浓厚的西部片 + 军事科幻气质。
- **美术风格**：3D 硬表面写实偏风格化。金属高光、发光能量线、极强的阵营色（蓝/红/绿），单位剪影差异极大——机枪兵（宽肩）、攻城坦克（低矮宽履带）、狂热者（高瘦双刃）。整体色调偏冷，特效（EMP、灵能风暴）是主要视觉记忆点。
- **视角与规模**：固定角度 3D 俯视，可缩放、不可旋转。人口上限 200，单局常见 50~150 个单位，极限运营可到 200 人口满编。
- **核心特色机制**：三族完全非对称 + 电竞级操作深度（微操、编队、宏观运营），把「操作上限」本身做成了卖点。
- **对小项目的参考价值**：**读图设计**的教科书。它的单位在俯视下几乎不需要看清细节就能判断兵种，这正是 2D 几何风格要学的东西。

### 3.2 魔兽争霸 III（Warcraft III，2002 / Reforged 2020）

- **世界观 / 主题**：高奇幻。艾泽拉斯大陆，人类、兽人、亡灵、暗夜精灵 + 燃烧军团，英雄叙事驱动。
- **美术风格**：3D 低模 + 卡通化写实。夸张的武器比例（比人还大的战斧）、饱和暖色、手绘质感贴图，整体像「会动的黏土模型」。
- **视角与规模**：固定角度 3D 俯视，可缩放。常规 50~100 人口，单局单位数量远少于星际 2。
- **核心特色机制**：**英雄单位**（升级、技能、物品栏）+ 人口维护费（upkeep）。英雄让「少量单位」也有养成感和叙事感，是 RTS 与 RPG 的第一次大规模融合。
- **对小项目的参考价值**：如果想吃「角色感」但不想做几百个单位，英雄制是最省资源的方案——玩家会盯着 1~3 个英雄看，美术预算可以集中投放。

### 3.3 帝国时代系列（Age of Empires，1997~）

- **世界观 / 主题**：历史写实。从石器时代到文艺复兴（AoE II）、从城堡时代到工业时代（AoE III）、中世纪到近代（AoE IV），以真实文明为单位。
- **美术风格**：写实考据。建筑按文明还原（哥特、伊斯兰、东亚屋顶形制），材质偏自然土色；AoE II 是 2D 等距预渲染精灵，AoE III/IV 是 3D 写实并带轻微风格化比例。
- **视角与规模**：2D 等距（AoE II）→ 3D 固定俯视可缩放（AoE III/IV），均不可旋转。常规 100~200 人口，单局 100+ 单位。
- **核心特色机制**：**四类资源（食物/木材/金币/石头）+ 时代升级 + 城墙与攻城**。经济运营的复杂度本身就是玩法核心。
- **对小项目的参考价值**：建筑与科技树是最大的成本项。若做历史题材，必须把建筑种类砍到 10 个以内，否则 2D 等距的单栋建筑绘制 + 施工帧就能吃掉全部预算。

### 3.4 命令与征服系列（Command & Conquer，含红色警戒，1995~）

- **世界观 / 主题**：架空近未来 / 架空冷战。泰伯利亚矿与 GDI vs NOD（正传），爱因斯坦杀死希特勒后的平行冷战（红警），后期转向夸张的超级武器与真人过场电影。
- **美术风格**：红警 2 是 2D 预渲染等距精灵，高对比、漫画化写实、极饱和；C&C 3 / 红警 3 转 3D 后是「塑料感写实 + 高光泛滥」，风格辨识度极高但经不起细看。
- **视角与规模**：固定等距 / 固定俯视，不可旋转。常规 50~150 单位，节奏极快。
- **核心特色机制**：**网格化基地建造 + 超级武器 + 真人过场**。基地是一格一格「长」出来的，这种建造快感是 C&C 的招牌。
- **对小项目的参考价值**：**基地建造的可视化反馈**最值得抄——每放下一栋楼都有明显的施工动画、占地格和音效，2D 下实现成本很低但爽感很强。

### 3.5 神话时代（Age of Mythology，2002 / Retold 2024）

- **世界观 / 主题**：神话。希腊、埃及、北欧、亚特兰蒂斯等万神殿，凡人军队 + 神话生物 + 神明力量。
- **美术风格**：3D 写实偏华丽，神话单位体型夸张（独眼巨人、九头蛇），神力特效（地震、流星雨）是视觉高潮。Retold 版重制了模型与光照，整体更明亮。
- **视角与规模**：3D 固定俯视，可缩放，不可旋转。常规 100~150 人口。
- **核心特色机制**：**选择主神决定科技树与神力**，加上「眷顾值」资源——玩家通过供奉获得神力，把「信仰」做成了可运营的资源。
- **对小项目的参考价值**：用「一个可选的神/派系」换取玩法差异，是资源有限时做内容深度的好办法（相当于用一个变量切换整套数值和特效）。

### 3.6 英雄连（Company of Heroes，2006 / CoH3 2023）

- **世界观 / 主题**：二战写实。诺曼底、市场花园、意大利战役，聚焦小队级战术。
- **美术风格**：去饱和写实。泥泞、废墟、动态光照、可破坏掩体，画面偏灰绿，强调「脏」和「真实」。
- **视角与规模**：3D 俯视，可旋转、可拉近到接近第三人称。单局 20~40 个**小队**（每队 3~6 人），不是单个士兵。
- **核心特色机制**：**掩体系统（黄/绿/红掩体）+ 占点资源 + 小队制**。单位不是「血量条」，而是「找掩体、压制成 suppression、侧翼包抄」。
- **对小项目的参考价值**：**掩体系统在 2D 网格上非常好实现**（给地块打掩体标签，判定减伤即可），能凭空多出一层战术深度，是 2D 小项目性价比最高的机制借鉴之一。

### 3.7 全面战争系列（Total War，2000~）

- **世界观 / 主题**：历史（幕府、罗马、中世纪、三国）与奇幻（战锤）双线。
- **美术风格**：3D 写实大规模。兵模精度中等但同屏数量极大，靠阵列、旗帜、尘土和光照营造史诗感。
- **视角与规模**：双层结构——回合制大地图 + 实时战术战斗，战斗镜头可自由旋转、缩放。单场数百至数千人。
- **核心特色机制**：**阵型、士气、侧翼与冲锋**。胜负不只看数值，还看部队朝向、疲劳和士气崩溃。
- **对小项目的参考价值**：**不建议做「全战式」规模**。但「士气值」这个轻量机制值得抄：单位在低士气时溃逃，比单纯的掉血死亡更有戏剧性，且只需一个数值 + 一个状态机。

### 3.8 家园（Homeworld，1999 / Homeworld 3，2024）

- **世界观 / 主题**：太空歌剧。流亡民族的母舰寻乡之旅，叙事克制、美术极简。
- **美术风格**：真空中的真实光照、大面积留白、极简 HUD；舰船是干净的硬表面，配合星云背景，气质偏「艺术片」。
- **视角与规模**：**真 3D 自由视角**（可 360° 旋转、俯仰）。单局几十至百余艘舰船。
- **核心特色机制**：**真 3D 舰队机动 + 母舰经济**。编队在三维空间中的高度差是战术的一部分。
- **对小项目的参考价值**：**反面案例**。真 3D 空间 + 2D 屏幕的操作映射是小团队灾难，Phaser 项目不要碰。

### 3.9 最高指挥官（Supreme Commander，2007）

- **世界观 / 主题**：硬科幻。三个阵营（UEF、Cybran、Aeon）在银河尺度打一场千年战争，单位是巨大的机甲与实验级兵器。
- **美术风格**：3D 写实机械。低模、金属灰 + 阵营色条、大量弹道与爆炸特效；单个模型不精致，但「钢铁洪流」的规模感是核心卖点。
- **视角与规模**：3D 可自由旋转、可拉远到战略视角。单方数百单位，多人/战役可达上千。
- **核心特色机制**：**战略缩放（strategic zoom）+ 流式经济（mass/energy）+ 实验级单位**。镜头拉远后直接变成一张战术地图。
- **对小项目的参考价值**：**「战略缩放」在 Phaser 里几乎零成本**（就是 camera.zoom）。这是 2D 小项目能白捡的一个「显得很大」的卖点。

### 3.10 要塞（Stronghold，2001~）

- **世界观 / 主题**：中世纪欧洲。领主经营城堡、管理粮食与民意、抵御围城。
- **美术风格**：早期 2D 等距手绘，暖土色、砖石细节丰富；后期转 3D 后偏卡通写实。
- **视角与规模**：2D 等距（初代）→ 3D 俯视。单局约 50~100 人，重心在建筑而非军队。
- **核心特色机制**：**城堡模拟 + 攻守双模式**。既要建城堡，也要用同一套城堡去打/守，经济链（麦田→面粉→面包）非常细。
- **对小项目的参考价值**：**「建造即防御」**的思路适合小项目——把城墙、塔、陷阱做成主要玩法，比做 20 种兵种更省资源。

### 3.11 国家的崛起（Rise of Nations，2003）

- **世界观 / 主题**：历史。从远古到信息时代，8 个时代连续演进。
- **美术风格**：2D 等距预渲染精灵，写实偏明亮，建筑随时代换外观。
- **视角与规模**：2D 等距固定，不可旋转。常规 100~200 人口。
- **核心特色机制**：**领土 / 国界 + 城市捕获**。建筑只能建在自己的领土内，边界随建筑扩张——把「地图控制」做成了可视化系统。
- **对小项目的参考价值**：**领土系统在 2D 网格上实现极简单**（一张归属图 + 边界渲染），却能显著提升「战略感」，非常适合 Phaser。

### 3.12 战锤 40K：战争黎明（Warhammer 40,000: Dawn of War，2004）

- **世界观 / 主题**：暗黑科幻（grimdark）。第 41 个千年的无尽战争，星际战士、兽人、灵族、混沌。
- **美术风格**：3D 写实厚重。大量金色、骷髅、哥特建筑与厚重装甲，去饱和 + 强对比，气质阴郁华丽。
- **视角与规模**：3D 俯视，可旋转缩放。单局 20~40 个小队。
- **核心特色机制**：**占点资源 + 小队制 + 同步击杀（sync kill）**。近战单位有专属处决动画，是「看起来值钱」的关键。
- **对小项目的参考价值**：**同步击杀是高性价比的「爽点」**——2D 下用 2~3 帧的特写或短暂慢动作就能复刻，成本极低但记忆点强。

### 3.13 光环战争（Halo Wars，2009 / Halo Wars 2，2017）

- **世界观 / 主题**：科幻。光环宇宙，UNSC 与星盟。
- **美术风格**：3D 写实明亮，干净的高科技表面 + 蓝紫能量，比星际 2 更「圆润友好」。
- **视角与规模**：3D 俯视，可旋转缩放（主机手柄优化）。单局 50~100 单位。
- **核心特色机制**：**预设基地 + 有限建造 + 强克制循环**。为手柄砍掉了复杂建造，把决策压缩到「造什么兵」。
- **对小项目的参考价值**：**简化操作是浏览器游戏的必修课**。光环战争证明了「砍掉建造细节」不会毁掉 RTS，反而更适合轻量平台。

### 3.14 北欧之地（Northgard，2018）

- **世界观 / 主题**：北欧神话。维京氏族在严冬大陆上拓荒、结盟、献祭。
- **美术风格**：扁平矢量插画 + 描边，低饱和冷色（灰蓝、墨绿、赭石），卡通化比例；季节变化会整体换色调，冬季有雪覆盖层。
- **视角与规模**：等距俯视，不可旋转。单局通常 20~50 个单位，规模很小。
- **核心特色机制**：**地块占领 + 季节 / 严冬生存 + 氏族差异化**。地图被切成有限地块，扩张受食物与木材约束，冬天会强制收缩。
- **对小项目的参考价值**：**最适合小团队对标的商业作品**。单位少、地图小、机制清晰、美术是「扁平插画」而非写实——2D 引擎反而比 3D 更适合这个风格。

### 3.15 亿万僵尸（They Are Billions，EA 2017 / 1.0 2019）

- **世界观 / 主题**：蒸汽朋克 + 僵尸末世。人类最后的殖民地在尸海中被围困。
- **美术风格**：等距 2.5D（3D 渲染成 2D 观感），暗棕 + 铜色 + 火光，高对比；僵尸是深色剪影，靠数量和密度制造压迫感。
- **视角与规模**：等距俯视，可小幅旋转/缩放。单局建筑数十栋、防守单位上百，**尸潮一波可达数千至上万**。
- **核心特色机制**：**基地建造 + 塔防 + 尸潮**。白天扩张经济，夜晚抵御成群的僵尸，节奏由「波次」驱动。
- **对小项目的参考价值**：**「波次 + 建造」是 2D 小项目最容易做出爽感的组合**。尸潮用同一种精灵堆量即可，渲染压力靠对象池和简化 AI 解决。

### 3.16 风暴之门（Stormgate，EA 2024-08 / 1.0 2025-08）

- **世界观 / 主题**：科幻 vs 恶魔。人类先锋（Vanguard）、地狱军团（Infernal）、天使势力（Celestial）三方在末世地球交战。
- **美术风格**：3D 风格化写实，偏明亮卡通硬表面，比星际 2 更「低龄/友好」，单位轮廓大而清晰。
- **视角与规模**：3D 固定俯视，可缩放，不可旋转。常规 100~200 人口，主打 1v1 竞技 + 3 人合作。
- **核心特色机制**：**免费游玩 + 1v1 竞技 + 合作模式**，试图复刻星际 2 的电竞生态，并加入「合作指挥官」式 PvE。
- **现状（已核实）**：2025-08 结束抢先体验发布 1.0；2026-04 其多人服务器托管商 Hathora 被收购后停止服务，线上模式一度全面下线，开发组紧急推出离线补丁并寻找新的托管方。口碑与在线人数均不理想。
- **对小项目的参考价值**：**警示案例**——「照着星际 2 做一个更好的星际 2」在商业上极难成立；同时提醒小项目：**在线服务依赖是真实风险，浏览器游戏应优先做可离线/单机可玩的核心循环**。

### 3.17 Beyond All Reason（BAR，开源，持续更新）

- **世界观 / 主题**：硬科幻。Total Annihilation 的精神续作，两个阵营（ARM / CORE）在星球表面进行机械化总体战。
- **美术风格**：开源引擎（Spring / Recoil）上的低模 3D，金属灰 + 阵营色，模型朴素但弹道、爆炸、残骸物理极其华丽——「用特效补模型」的典型。
- **视角与规模**：3D 可自由旋转、可拉到极高视角。**单方数百单位，8v8 多人局全局可达数千**。
- **核心特色机制**：**流式经济（金属/能量，无「矿点」限制）+ 大规模编队 + 开源免费**。资源是连续产出而非采集点，经济管理更像「调水阀」。
- **现状（已核实）**：2026-06 宣布与发行商 Hooded Horse 合作，将以付费 Premium Edition 登陆 Steam（含单人战役），**IP 归团队、代码继续保持 GPL 开源**；官网新闻与引擎更新持续到 2026 年下半年。
- **对小项目的参考价值**：**「模块化单位 + 换色阵营 + 特效堆量」的极致示范**。它证明美术精度不是 RTS 的门槛，规模和手感才是。

### 3.18 0 A.D.（开源，Wildfire Games）

- **世界观 / 主题**：古代历史。公元前 500 年至公元 1 世纪的地中海与近东文明（罗马、雅典、斯巴达、波斯、迦太基、日耳曼等）。
- **美术风格**：3D 写实考据。建筑与兵种按文明还原，暖色地中海光照，模型精度中等。
- **视角与规模**：3D 可旋转、可缩放。常规 100~200 人口。
- **核心特色机制**：**领土 / 建筑扩张 + 文明差异化 + 完全开源（GPL）**，资源与科技树接近帝国时代，但更强调「前线建筑推进」。
- **现状（已核实）**：2026-02-18 发布 Release 28「Boiorix」，**是首个去掉 Alpha 标签的正式版本**，新增日耳曼阵营并优化了中文渲染。
- **对小项目的参考价值**：**开源资产与代码可参考**（注意 GPL 传染性，商用需谨慎）；同时它的「文明少而差异大」策略适合小团队。

### 3.19 风暴崛起（Tempest Rising，2025-04）

- **世界观 / 主题**：架空冷战 / 核战后。全球防御部队（GDF）与王朝（Dynasty）在风暴笼罩的废土上争夺一种会生长的晶体资源。
- **美术风格**：3D 写实，明确的 C&C 血统：高对比、饱和阵营色、夸张的爆炸与建筑比例，配合动态植被与风暴天气。
- **视角与规模**：3D 固定俯视，可缩放。常规 100+ 单位，节奏接近红警 2。
- **核心特色机制**：**经典网格基地建造 + 阵营非对称 + 可交互的动态地形/风暴**，明确对标「老派 C&C」。
- **对小项目的参考价值**：**「复古 C&C 配方 + 现代包装」在 2025 年仍有市场**，说明 2D 俯视 RTS 的玩法骨架没有过时，缺的只是包装。

### 3.20 ZeroSpace（EA 2026-07）

- **世界观 / 主题**：科幻。人类指挥官 Aster 在银河中为人类争取生存空间，带队友关系与剧情选择。
- **美术风格**：3D 风格化写实、电影化运镜，整体偏「星际 2 + 质量效应」的混合气质。
- **视角与规模**：3D 俯视，可缩放。规模接近星际 2。
- **核心特色机制**：**RTS + RPG 混合战役 + 合作「银河战争」模式**，用叙事和养成降低 RTS 的上手门槛。
- **现状（已核实）**：2026-07-20 进入抢先体验（Early Access），此前在 Steam Next Fest 提供过含 5 种模式的 Demo。
- **对小项目的参考价值**：**「RTS 外壳 + 轻 RPG 成长」是当前拉新主流**，小项目可以用「指挥官升级 / 单位解锁」这种极轻量的方式蹭这个趋势。

## 5. 针对本项目的 3 个风格方向建议

前提假设（来自现有设计文档）：基础玩法为采矿、造工人、造兵、基地攻防；美术暂用几何色块；技术栈 Vite + TypeScript + Phaser 3；团队规模小，无 3D 管线。
以下估算以「1 个可玩阵营 + 1 个敌方阵营（可复用模型换色）+ 12 种单位 + 8 种建筑 + 1 套地形」的 MVP 为基准。

### 方向 A（首选）：战术全息 / 扁平几何科幻

**一句话**：把现在的几何色块「正式化」——深色地面 + 半透明网格 + 高饱和阵营色 + 发光描边，做成「指挥终端全息沙盘」的观感。

- **为什么选它**
  - 直接承接现有几何占位美术，**不需要推翻任何已有资源**，是唯一「零返工」的方向。
  - 科幻题材允许「同一底盘 + 换炮塔/换颜色」生成新单位，天然适配小团队。
  - 俯视下剪影最清晰，玩家 0.3 秒能分清工人/步兵/坦克，符合 RTS 的读图刚需。
  - 暗背景 + 发光线条能掩盖贴图精度不足，且用 Phaser 的 blend mode / 后处理就能出效果。
- **需要多少美术资源**
  - 单位 12 种 × 1~2 帧（本体静止帧 + 炮口/履带动画）≈ 20 张图；建筑 8 种 × 2 帧（建造中/完成）≈ 16 张。
  - 特效靠程序化：粒子、线段、圆环、扫描线，**0 张手绘图**。
  - 地形 1 套 tile（8~16 种）+ UI 一套矢量图标（约 20 个）。
  - 估算：**美术 1~2 人周**，且大部分可用代码/程序化生成，外包成本几乎为零。
- **Phaser 2D 俯视角实现难度：低**
  - 正交俯视，无需等距坐标转换与深度排序；`Container` + `Graphics` + `Particles` 即可。
  - 单位动画可用「整体旋转 + 缩放脉冲 + 拖尾」替代逐帧，`tween` 一把梭。
  - 200 单位内用对象池 + 简单网格寻路（A* 或流场）足够，60fps 无压力。
- **对标作品**：Beyond All Reason（模块化 + 特效堆量）、Mindustry（极简几何 + 高可读性）、Rusted Warfare（同类型 2D 玩法骨架）。
- **风险**：科幻是红海，容易被说「像星际/像 BAR」；需要靠一个视觉钩子（如全息网格、扫描线、数据流 UI）做差异化。

### 方向 B（次选）：像素复古 C&C（90 年代等距）

**一句话**：把游戏做成「红警 2 的当代小体量复刻」——32~48px 像素单位、等距地块、饱和阵营色、带扫描线的 CRT UI。

- **为什么选它**
  - 像素风对「画得不够好」极其宽容，且玩家对 RTS 像素风有强烈的怀旧认同。
  - 素材生态成熟（大量可商用/CC0 像素 RTS 素材包），起步成本低。
  - 与「采矿—造兵—推基地」的经典循环气质最匹配，不需要额外的世界观解释。
- **需要多少美术资源**
  - 单位 12 种 ×（待机 4 + 移动 6 + 攻击 4）≈ 170 帧；建筑 8 种 × 2~4 帧 ≈ 24 帧。
  - 等距地形 tile 约 100~150 块（含过渡与装饰）。
  - UI 一套像素面板 + 图标（约 30 个）。
  - 估算：**美术 4~6 周**（外包约 1~3 万元区间，视精度而定）。
- **Phaser 2D 俯视角实现难度：中**
  - 若做真等距：需要菱形坐标 ↔ 屏幕坐标转换、按 y 排序深度、等距寻路，**额外 1~2 周工程量**。
  - 折中方案：用「正交俯视 + 45° 斜视精灵（伪等距）」，视觉接近等距但不用改寻路，**推荐这条**。
  - 像素风必须在 Phaser 里开 `pixelArt: true` 并禁用纹理平滑，缩放要用整数倍，否则会糊。
- **对标作品**：8-Bit Armies（像素 + 经典建造）、红警 2（等距预渲染的审美源头）。
- **风险**：像素 RTS 同质化严重；等距 + 大量动画帧会显著拉长制作周期；美术一旦风格不统一（有的 32px 有的 48px）会立刻显廉价。

### 方向 C（差异化）：末世废土 / 暗色蒸汽朋克

**一句话**：暗棕 + 铜色 + 火光，采矿点做成冒烟的废墟矿井，基地是拼凑的铁皮堡垒，敌人是成群涌来的深色剪影。

- **为什么选它**
  - 暗色调天然掩盖细节缺失，**同样的美术水平在暗色下看起来更「贵」**。
  - 「基地建造 + 波次防守」与现有玩法（采矿、造兵、基地攻防）几乎完全重合，不需要改玩法。
  - 剪影尸潮/机械潮用同一种精灵堆量即可，是**最容易做出「爽感画面」**的路线，直播和短视频传播友好。
  - 与 A、B 相比差异化最强，不容易被直接拿去和星际/红警对比。
- **需要多少美术资源**
  - 单位 10 种 × 2~3 帧（可用「骨架 + 换装」复用）≈ 30 张；建筑 8 种 × 2 帧 ≈ 16 张。
  - 环境素材是大头：废墟装饰、烟尘、火光、雾层（约 30~40 个装饰件，但可大量复用）。
  - 特效靠叠加：火光点光源、烟雾粒子、屏幕暗角（vignette），**用 shader/后处理代替手绘**。
  - 估算：**美术 2~3 周**，介于 A 和 B 之间。
- **Phaser 2D 俯视角实现难度：低~中**
  - 俯视 + 暗色调 = 最容易出效果的组合；用 `Light2D` 或简单的径向渐变叠层就能做「火光照明」。
  - 大量同屏单位需要对象池 + 简化 AI（ flocking / 直线冲锋），Phaser 的自定义 update 循环能扛住 300~500 个简单单位。
  - 难点在「氛围调校」而非技术：需要一套统一的色调 LUT 和后处理，否则容易脏。
- **对标作品**：亿万僵尸（暗色 + 波次 + 建造）、风暴崛起（核战后废土 + C&C 骨架）。
- **风险**：暗色画面在低亮度屏幕上可读性差，UI 与单位描边必须额外做对比处理；「末世」题材在中文市场略疲劳，需要靠玩法钩子（如可破坏地形、昼夜循环）撑住。

### 5.1 三个方向的横向对比

| 维度 | A 战术全息科幻 | B 像素复古 C&C | C 末世废土 |
|---|---|---|---|
| 与现有几何占位美术的兼容度 | 100%（可直接延续） | 0%（需全部重画） | 40%（几何单位可保留，需重做环境） |
| 美术工作量（MVP） | 1~2 人周 | 4~6 人周 | 2~3 人周 |
| Phaser 实现难度 | 低 | 中（等距）/ 低（伪等距） | 低~中 |
| 差异化程度 | 低（红海） | 中（怀旧） | 高 |
| 直播/传播友好度 | 中 | 中 | 高 |
| 扩展性（后续加阵营/兵种） | 极高（换色换炮塔） | 中（每兵种都要画） | 高（可复用骨架） |
| 主要风险 | 被说「像星际/BAR」 | 同质化 + 工期长 | 画面偏暗、题材疲劳 |

### 5.2 落地建议（务实版）

1. **主线走 A，包装借 C 的氛围。** 用几何 + 发光的「全息沙盘」做底层，把地图色调压暗、加火光与雾，既保留零返工优势，又拿到末世的差异化与传播力。这是成本最低、上限也不差的最优解。
2. **MVP 阶段不要做等距。** 正交俯视 + 轻微 3/4 视角精灵，能省掉坐标转换、深度排序、等距寻路三块工程量；等玩法验证完再考虑升级。
3. **先做「读图测试」。** 在只有几何色块的阶段，就让 5 个没看过设计文档的人玩 5 分钟，问他们「哪个是工人、哪个是兵、哪个能打谁」。如果答不出来，问题在剪影和配色，不在贴图精度——这时候加美术是浪费。
4. **美术预算优先给「建筑」而不是「单位」。** 玩家 80% 的时间在看基地，建筑是画面的主体；单位只需要剪影正确、朝向清楚、有攻击反馈。
5. **不要碰真 3D、不要碰在线服务依赖。** 家园和风暴之门分别从「操作映射」和「服务托管」两个方向证明了这两件事对小团队的风险。
