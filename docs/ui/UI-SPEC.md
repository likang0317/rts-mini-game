# UI-SPEC · 轩辕 RTS 界面规范

> 适用文件：`docs/ui/ui-a.html`（方案 A，已交付）
> 后续方案 B / C 必须复用本文第 5 章的 token，不得另起一套色板与字号。
> 设计基准：1920×1080；最小适配：1440 宽（等比缩放，不重排）。

---

## 1. 设计定位

一句话：**玄黑为底、土黄描金、玉青点眼、朱砂示警**的“礼器式 HUD”。

三条硬规则：

1. **不做赛博荧光**。所有高亮都靠“描金边 + 内发光 + 纸纹噪点”堆层次，而不是靠提高饱和度。
2. **地图是画，HUD 是框**。HUD 的明度必须低于地图受光区，形成“画框中看界画”的关系；HUD 不允许比战场更抢眼。
3. **德望不是资源，是叙事**。它独占一块面板，用玉璧徽记 + 金色环轨 + 宗庙光晕呈现，绝不与谷/木/石/玉并排放进同一条资源带。

---

## 2. 画布与缩放

```
.stage  1920 × 1080
scale = min(innerWidth / 1920, innerHeight / 1080)
transform: translate(-50%,-50%) scale(scale)
transform-origin: center center
position: absolute; left:50%; top:50%
```

- 1920×1080 下 1:1，不做任何重排。
- 1440×810 下 scale = 0.75，HUD 尺寸、字号、间距全部等比缩小，不塌、不换行。
- 1440×900（16:10）会上下各留 45px 黑边，背景为径向深色渐变，属预期表现。
- 禁止用 `vw/vh` 直接写组件尺寸；所有尺寸都是 1920 基准下的 px。

## 3. HUD 骨架：成熟 RTS 为什么这么放

| 作品 | 资源条 | 小地图 | 命令卡 | 单位信息 | 关键逻辑 |
|---|---|---|---|---|---|
| 星际争霸 II | 顶部左（矿物/瓦斯/人口） | 左下 | 底部中央偏右 | 命令卡左侧 | 资源是“全局存量”，放最上不参与操作回路；命令卡贴近屏幕中心偏下，因为玩家 80% 的点击落在这里 |
| 帝国时代 II / IV | 顶部通栏 | 左下 | 底部中央 | 命令卡左侧 | 同 SC2，但资源带做成通栏木框，强化“经营”的存在感 |
| 魔兽争霸 III | 顶部左 | 左下 | 底部中央 | 命令卡左 | 英雄头像与技能占掉命令卡左侧，信息密度最高；英雄单位必须“一眼可辨” |
| 命令与征服 / 红警 | 右侧竖栏（建筑/生产） | 右下 | — | 无独立面板 | 侧栏把建造流程做成“树”，视野更宽，但单次操作路径长 |
| 风暴之门 | 左下 | 左下上方 | 底部中央 | 命令卡左 | 明确把“资源 + 人口 + 小地图”打包进左下角一个视觉块，减少眼球跨度 |

共同的底层原因，只有三条：

1. **视线落点**：RTS 的注意力中心是屏幕中部偏下的战场，不是 HUD。HUD 必须待在“余光可及”的边缘，任何重要读数都不能要求玩家把视线移到角落再移回来。
2. **拇指/鼠标行程**：命令卡是点击频率最高的区域，必须靠近鼠标自然停留位（屏幕中下），且按钮尺寸足够大（≥ 88px）以承受连续快速点击。
3. **小地图在左下的原因**：左下与资源条同侧，形成“看资源 → 看小地图 → 点小地图”的单侧闭环；同时左利手玩家的鼠标通常停在右侧战场，左下不会遮挡操作。放在右下会和命令卡争夺同一块拇指区。

## 4. 方案 A 的取舍（已落地）

### 4.1 为什么命令卡居中

- 本作的**核心操作是“农人 → 建造 → 祭祀”三段式**，不是高频微操。命令卡需要同时容纳 5 个 96px 指令与 3 张建造卡，只有居中才够宽（920×288），且不会挤占左右信息区。
- 居中让“选中信息（左） → 指令（中） → 战报（右）”形成一条**从左到右的阅读顺序**：先确认选了什么，再决定做什么，最后看结果。
- 命令卡左右各留 100px 呼吸位（`left:500 / width:920`），在 1440 缩放下仍有 75px，不会贴边。

### 4.2 德望怎么做出区分度

1. **位置升格**：独占左下最上方一块 380×58 的独立面板，排在资源条之前；资源条只放谷/木/石/玉/人口五项。
2. **形态升格**：左侧是一枚 44px 的**玉璧徽记**（双环 + 篆字“德”），带 `drop-shadow(0 0 8px rgba(200,162,74,.28))` 的呼吸光晕，是全 HUD 唯一带外发光的徽记。
3. **读数升格**：数值 19px/600（资源值 17px/500），并额外显示“受禅尚需 38”的朱砂提示与 50% 刻度线（`--cinnabar-500` 竖线），把“进度”叙事化。
4. **不并排**：德望永远不出现在五连资源格中，避免被读成“第六种资源”。

### 4.3 其它取舍

- **小地图在左下、且在资源条下方**：保留“看-点”单侧闭环；舆图上方留 6px 间隙，用同宽面板包住，视觉上是一个“左下仪表块”。
- **右侧只放战报与编队**：本作不需要建筑树侧栏，右侧留给“发生了什么”，宽度 340 足够放 3 条战报 + 2 组编队。
- **底部整体高度 300px**：低于 1/4 屏，保证战场可见面积 ≥ 72%；三段面板高度 288/280，避免等高带来的呆板。
- **顶部只做身份与天气**：不承载任何操作，纯氛围 + 状态提示（大雾 −15% 命中）。

### 5.2 字体与字号阶梯

字体栈（系统字体，不引外部字体）：

```
--serif: "Source Han Serif SC","Noto Serif SC","Songti SC","STSong","STZhongsong","SimSun",serif
--sans:  "PingFang SC","Microsoft YaHei","Noto Sans SC","Hiragino Sans GB",sans-serif
--num:   "Bahnschrift","DIN Alternate","Segoe UI",var(--sans)
--mono:  "Cascadia Mono","Consolas","SFMono-Regular",monospace
```

| 级别 | 字号/行高 | 字重 | 字体 | 字距 | 用途 |
|---|---|---|---|---|---|
| Display | 25 / 1.1 | 600 | serif | .22em | 势力名「轩辕」 |
| H1 | 22 / 1.1 | 600 | serif | .1em | 单位名（农人/祭坛） |
| H2 | 17 / 1 | 600 | num | .01em | 资源数值 |
| H3 | 15 / 1.2 | 600 | serif | .1em | 任务标题、操典标题 |
| H4 | 13 / 1 | 600 | serif | .18~.2em | 面板标题「营造」 |
| Body | 11 / 1.6 | 400 | sans | .06em | 说明文字 |
| Label | 10 / 1 | 400 | sans | .12~.2em | 资源名、标签 |
| Micro | 9 / 1 | 400 | sans | .16~.22em | 眉标、统计项名 |

规则：

- **中文标题一律 serif，数值一律 num**；正文 sans。
- 所有数值容器加 `font-variant-numeric: tabular-nums`，保证跳动时不抖。
- 最小字号 9px（仅眉标），正文最小 10px；1440 缩放下 10px → 7.5px，只用于非关键信息。
- 字距是“古意”的主要来源：标题 .2em，标签 .12em，正文 .04em。

### 5.3 间距系统

4px 基数，常用档位：`4 / 6 / 8 / 10 / 12 / 14 / 16 / 18 / 20 / 24 / 26`。

| 场景 | 值 |
|---|---|
| 面板内边距（大） | 16~18px |
| 面板内边距（小/条） | 10~12px |
| 面板之间 | 6px（左/右栈内部），20px（距屏幕边） |
| 面板标题下 | 10~14px |
| 卡片内边距 | 8~10px（建造卡 12px） |
| 图标与文字 | 7~10px |
| 按钮网格间隙 | 12px |
| 分区线上下 | 10 / 12px |

### 5.4 描边 / 圆角 / 阴影 / 纹理

**圆角：全局 0。** 礼器、夯土、木构都是直边；唯一的“圆”是玉璧与徽记（`border-radius:50%`）。B/C 不允许引入 8px/12px 圆角卡片。

**面板基座**（`.panel`，所有 HUD 容器的唯一底）：

```css
background:
  radial-gradient(130% 150% at 50% -30%, rgba(200,162,74,.10), rgba(200,162,74,0) 55%),
  linear-gradient(180deg, rgba(39,40,30,.965) 0%, rgba(25,26,18,.98) 52%, rgba(14,15,10,.985) 100%);
border: 1px solid rgba(200,162,74,.26);
box-shadow:
  inset 0 1px 0 rgba(244,238,220,.07),
  inset 0 0 0 1px rgba(0,0,0,.35),
  0 14px 34px rgba(0,0,0,.42),
  0 2px 6px rgba(0,0,0,.5);
```

**三层质感**（缺一不可）：

1. **角饰**：四角 13×1px 土黄短线（`.panel::before`），opacity .55。
2. **纸纹噪点**：140×140 的 `feTurbulence` 内联 SVG，opacity .05，`mix-blend-mode:overlay`。
3. **顶部受光**：`inset 0 1px 0 rgba(244,238,220,.07)`，模拟上方光源。

**描边规则**：

- 默认 1px；激活/悬停 1px 但提亮到 `rgba(216,182,94,.55)`。
- 选中态用**双层**：外 1px 土黄 + 内 1px 暗影（`inset`），不使用 2px 粗描边。
- 虚线只用于“临时/待放置”（建造 ghost、框选框），不用在常规组件上。

## 6. 组件清单与状态

### 6.1 面板 `.panel`

| 状态 | 表现 |
|---|---|
| 默认 | 上述基座 |
| 嵌在控制台内 | 去掉外层阴影，仅保留 1px 描边 + 内受光 |
| 浮层（结算） | 加 `backdrop-filter: blur(3px)` 与外投影 0 24px 60px |

标题 `.ph`：28px 高，左侧 5px 旋转 45° 土黄菱形（`box-shadow: 0 0 8px`），serif 13px/.2em。

### 6.2 资源条 `.res`

- 5 项单行，高 46px，每项 `gap:5px`，图标 22×22，数值 17px，名称 10px。
- 人口为独立窄格（86px），带「9/16」双色：占用玉白、上限灰。
- 数值变化时只做数值替换 + 200ms 土黄色闪烁，不做位移。

### 6.3 德望面板 `.dewang-panel`

- 58px 高，徽记 44px，进度条 4px（土黄渐变 + 外发光），50% 处有朱砂刻度线。
- 副行：左「受禅尚需 38」（朱砂），右「附祀 2 / 3」（灰）。

### 6.4 指令按钮 `.cmd`

- 96×96，1px 土黄描边，垂直渐变（`#303124 → #13140D`）。
- 内部结构：24px 图标（上 16px）+ 12px 名称 + 右下角 9px 键位。
- 状态：

| 状态 | 变化 |
|---|---|
| 默认 | 图标 `--bone-300`，名称 `--bone-200` |
| hover | 边框 `rgba(216,182,94,.55)`，背景上浮一档，图标转 `--earth-200`，`inset 0 0 16px rgba(200,162,74,.14)` |
| active（按下） | 整体下沉 1px，背景压暗，`box-shadow` 收为内阴影 |
| 已选/持续 | 左上角 4px 土黄三角，边框提亮，名称转 `--earth-200` |
| disabled | 整体 `opacity:.38`，`filter:saturate(.25)`，图标 `--muted-500`，不响应 hover，无角标 |
| 热键 | 右下角 9px num，`--muted-400`；hover 时转 `--earth-300` |

### 6.5 建造卡 `.build-card`

- 178×约 176，包含：16px 建筑图标 + 17px serif 名称 + 11px 用途 + 2×2 造价格 + 底部状态行。
- 造价格：12px 图标 + 13px num；不足的一项整格转朱砂，其余保持灰。
- 状态：

| 状态 | 表现 |
|---|---|
| 可建造 | 边框土黄 .24，底部「可营造」玉青 |
| 推荐 | 右上角朱砂小签「推荐」，边框提亮 |
| 经费不足 | 斜向 45° 暗纹（`repeating-linear-gradient` 8px），整体 opacity .62，底部朱砂徽标「石木不足 10」，造价不足项朱砂 |
| hover | 仅可建造态响应：边框提亮 + 图标外发光 |
| 选中 | 同指令的 active 态 |

### 6.6 祭祀卡 `.ritual` + 预览

- 2×2 网格，`grid-template-rows:1fr 1fr auto`，卡片自适应高度，不允许内容溢出。
- 卡内：13px 名称 + 10px 效果 + 10px 消耗（左下角玉量）。
- 预览区：64px 玉璧环（中置数值 18px），右侧 3 行「消耗玉 / 德望 / 加成」；底部主按钮「开始祭祀 P」。
- 不可祭：整卡 opacity .55 + 朱砂「玉不足」。

### 6.7 选中信息 `.sel-head`

- 头像 92×92，`::after` 内嵌 3px 描边；右下角等级/数量小签。
- 名称 22px serif，状态行 11px（进行中的动作转玉青）。
- 气血条 6px 高：我方土黄渐变，敌方朱砂渐变；数值浮在条右上方 10px。
- 属性行 `.sel-stats` 固定贴底（`margin-top:auto`），4 项等分，项名 9px、值 12px。

### 6.8 多选卡 `.multi-card`

- 高 54，宽等分，底部 3px 血条；敌方卡描边转朱砂。
- 数量 > 12 时改为「图标 + ×N」，不再逐卡展示。

### 6.9 舆图 `.minimap`

- 320×约 120 的斜切梯形视野框（虚线），图例在右侧 96px 宽。
- 地形用 4 色低饱和块：林地 `#3E4A2E`、田 `#8A7A46`、石 `#6E6A58`、水 `#31514A`；敌情用朱砂 3px 点，视野框用玉白虚线。

### 6.10 状态条 `.statebar`（仅设计稿）

- 顶部居中，6 个切换钮（1–6），深底 + 10px 字。属于评审工具，正式游戏删除。

### 6.11 受禅结算 `.victory`

- 全屏 `rgba(6,7,4,.72)` 遮罩 + 3px 模糊。
- 卡片 880×约 470：金色双线框（外 1px .55 / 内 1px .18，内缩 6px），四角 L 形角饰 18px。
- 结构：玉璧徽记（禅）→ 眉标「天命所归 · 德望 100」→ 28px「受 禅」→ 一句礼辞 → 四格数据 → 两句小字 → 双按钮。
- 右下角朱砂印章（旋转 −6°，2px 双框）。

## 7. 图标规范

- **画布**：24×24 viewBox，视觉重心居中，安全区 20×20。
- **风格**：几何剪影 + 细描边。主体用 `fill:currentColor`（不透明），关键结构用 `stroke:currentColor` 1.5px，`stroke-linecap:round`。
- **通透感**：深色底上不使用纯白填充，统一 `currentColor`，由父级给 `--bone-300` / `--earth-200` / `--jade-300`；需要“镂空”时用 `fill-rule:evenodd` 或叠一个背景色小矩形，不用 opacity 挖空。
- **24px 可辨**：任何图标在 24px 下必须能说出是什么；细节不超过 6 条线；不做文字、不做渐变。
- **尺寸档**：20（顶栏按钮）/ 22（资源）/ 24（指令、卡片）/ 28（单位头像底）/ 44–64（徽记）。
- **所有图标内联 SVG `<symbol>` + `<use>`**，禁止 emoji、禁止占位方块、禁止外链图片。
- 现有编号：`i-*`（资源/功能）、`c-*`（指令）、`b-*`（建筑）、`u-*`（战场单位）、`p-*`（头像）、`r-*`（天气）。

## 9. 动效

| 对象 | 时长 | 曲线 | 说明 |
|---|---|---|---|
| hover | 160–180ms | ease-out | 只动颜色、边框、内阴影，不动尺寸 |
| 状态切换 | 220ms | ease | 场景层淡入淡出 |
| 数值变化 | 200ms | ease-out | 土黄闪一下，不滚动 |
| 德望徽记 | 3.2s | ease-in-out alternate | 光晕呼吸，幅度 ≤ 20% |
| 受禅浮层 | 320ms | cubic-bezier(.2,.8,.2,1) | 遮罩淡入 + 卡片 1.02→1 |

禁止：弹跳、旋转入场、大面积位移、彩色霓虹扫光。

## 11. 给 B / C 的复用说明

- 直接复制第 5 章的 `:root`，**一个变量都不要改**。
- 面板基座、标题条、指令按钮、造价格、祭祀卡、结算浮层作为“原子组件”复用；B/C 只重排位置与容器比例。
- B（侧栏式）：右侧栏宽度不得低于 300px，否则造价格与建筑名会换行；资源条移到左上，德望仍需独立，不能压进资源带。
- C（沉浸窄边框）：面板高度可压到 220px，但指令按钮不得小于 88px，德望徽记不得小于 40px；半透明面板的底透明度不得低于 0.82，否则深色地图上文字会糊。
