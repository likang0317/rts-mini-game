# 01 学习路线：入门、进阶、精通

## 先说这套路线怎么用

你不是"学游戏开发"，你是"把一个 RTS 做到手机上能玩"。所以每一档都不按知识点组织，按**能交付什么**组织。

三档之间的关系是**替换**，不是叠加：入门档做完，你手上有一个能装、能走、能采的 APK；进阶档把它变成一局能分出胜负的游戏；精通档把它变成一部能持续更新、帧率可控、平衡有据的作品。

每档都写四件事：**要会什么、拿本项目练什么、怎么算过关、大概多久**。时间都是估算，按每天投入 3-4 小时、有前端经验、没做过游戏来算。

| 档位 | 目标 | 估算 | 对应章节 |
| --- | --- | --- | --- |
| 入门 | 手机上能装、能选中、能移动、能采一种资源 | 2-3 周 | 02、03、04、13、16 的 P0-P2 |
| 进阶 | 一局 10 分钟能打完的完整循环 | 4-6 周 | 05、06、07、08、09、11 |
| 精通 | 可平衡、可诊断、可发布、可维护 | 2-3 个月 | 10、12、14、15 |

## 入门档：从"能跑"到"手机上能玩"

### 这一档要会什么

不是"会用 Phaser"，是四件具体的事：

1. **知道逻辑时间和渲染时间是两个时钟。** 能写出固定步长累加器，能解释为什么不能用 `delta * speed`。
2. **能画出逻辑层和渲染层的边界。** 知道哪些字段属于状态、哪些属于画面，能在一个文件里指出越界的代码。
3. **能设计一条手指能走完的操作链。** 知道 tap、长按、双指分别该做什么，知道为什么右键和悬停不能用。
4. **能独立打出一个 debug APK 并装到真机。** 包括 `base: './'`、`adb install`、`chrome://inspect`、`adb logcat` 四个环节。

### 拿本项目练什么

按顺序做，每一步都有可验收的产物：

**练习 1：把 `updateUnits` 改成固定步长**

- 目标文件：`src/scenes/MainScene.ts:246-264`
- 要求：新增 `accumulator`，逻辑固定 `1/60` 秒推进，`delta` 夹在 250ms 内，单帧最多 5 步。
- 验收：DevTools 把 CPU 降速 6 倍，单位从 A 走到 B 的耗时误差 < 0.2 秒。
- 参考：第 02 章。

**练习 2：把状态从场景里抽出来**

- 目标：新建 `src/game/sim/`，把 `Unit` 拆成 `UnitState`（纯数据）和 `UnitView`（Phaser 对象）。
- 要求：`src/game` 下搜不到运行时 `Phaser` 引用（`import type` 可以）。
- 验收：把 `MainScene` 里的 `syncViews` 整段注释掉，逻辑照常跑，只是画面不动。
- 参考：第 03 章。

**练习 3：实现 tap-tap 移动**

- 目标文件：`src/scenes/MainScene.ts:106-149`（整套输入要重写）
- 要求：单指点单位选中；点地面移动；点空地取消选中；位移 < 8px 才算点击；双指缩放；单指拖空白平移。
- 验收：单手在真机上完成"选中一个单位 → 让它走到屏幕另一头"，连续 10 次不误触。
- 参考：第 04 章。

**练习 4：打出第一个 APK**

- 要求：Capacitor 接入、横屏锁定、安全区、DPR 压到 2。
- 验收：APK 装到手机，断网能启动，刘海不挡 HUD，旋转不重启。
- 参考：第 13 章。

### 怎么算过关

五条，缺一条都算没过：

- [ ] 手机上 APK 能启动，断网也能玩。
- [ ] 三个单位能选中、能移动、能取消，单手完成。
- [ ] 切后台 30 秒回来，单位位置和逻辑没有跳变。
- [ ] `src/game/` 不依赖 Phaser 运行时。
- [ ] 你能不看文档，向别人解释"为什么 `delta * speed` 在 RTS 里不能用"。

### 估算

- 有前端经验的人，第一档大约 **2-3 周**。其中打包环境（JDK、SDK、Gradle 首次下载）会吃掉 1-2 天，这是正常的，不是你笨。
- 如果你从来没碰过 Android 工具链，把打包那两天单独留出来，别安排在状态最差的晚上。

## 进阶档：从"能走"到"能打完一局"

### 这一档要会什么

1. **能定义一条完整的操作链**：选中 → 下令 → 目标点分配 → 单位执行 → 反馈。
2. **能写网格 A\***，并且知道为什么多单位不能各算各的。
3. **能把地图变成数据**：地形、资源点、占位、范围查询。
4. **能设计战斗结算顺序**，知道哪些 bug 是"同时结算"造成的。
5. **能倒推经济曲线**：从"每秒产出"推造价、建造时间、人口节奏。
6. **能让玩家看懂战场**：信息分层、血条、指令反馈、镜头。

### 拿本项目练什么

**练习 5：给农人加一条采集路径**

- 要求：农人从大邑出发 → 走到林地 → 采 10 木 → 走回大邑 → 资源 +10 → 自动折返。
- 数据用 `DESIGN-v2.md:3.4`：木 10/趟、单程约 3 秒；石 8/趟、单程 4 秒；玉 10/趟、单程 4 秒。
- 验收：资源数字每趟准确 +10，农人不会卡在资源点或基地里。
- 参考：第 09 章。

**练习 6：实现长按框选和编队**

- 要求：空白处长按 250ms 进入框选；底部 3 个编组槽，点击选中、长按写入、双击居中。
- 验收：能一次框住 8 个农人，存进编组 1，切到别处后一键召回。
- 参考：第 04、05 章。

**练习 7：写 A\* 并让 20 个单位绕过建筑**

- 要求：40×30 网格，八方向，禁止斜穿墙角；路径请求分帧处理。
- 验收：20 个单位从基地一侧走到另一侧，不出现"全部挤在一条线上抖动"。
- 参考：第 06 章。

**练习 8：做一个最小的战斗**

- 要求：族兵攻击农人，攻击间隔、伤害、护甲、死亡、索敌各一条规则；两段式结算。
- 验收：3 个族兵打 5 个农人，10 秒内出结果，没有"打死了还在打"或"两个单位互相穿过"。
- 参考：第 08 章。

**练习 9：把"采集 → 建造 → 造兵 → 打掉敌方基地"串成一局**

- 要求：一局 10 分钟内能结束，有胜负界面。
- 验收：你自己连续玩三局，每局都能在 8-12 分钟内结束，且没有卡死。
- 参考：第 16 章。

### 怎么算过关

- [ ] 一局 10 分钟能从头走到胜负，不需要重启。
- [ ] 20 个单位同屏移动不互相穿透、不长时间堵死。
- [ ] 四资源中至少三种能稳定采集并正确结算。
- [ ] 战斗没有"过杀"（一队兵同时打一个已死目标）和"追到天涯"。
- [ ] 手机上单手能完成"选农人 → 造建筑 → 选兵 → 进攻"全链路。
- [ ] 100 单位同屏，目标机型 ≥ 30fps。

### 估算

- **4-6 周**。寻路和触屏交互各占一周左右，战斗和经济各占一周。
- 如果你的目标只是"自己玩"，第 9 条练习做完就可以停，不必进精通档。

## 精通档：从"能玩"到"能维护、能发布、能调"

### 这一档要会什么

1. **确定性**：能录一局操作、重放、逐帧比对状态哈希。
2. **性能诊断**：能定位到"是填充率、绘制调用、GC 还是寻路尖峰"，而不是笼统说"卡"。
3. **数值方法**：能从产出率推造价与工期，能维护一张可追溯的平衡表。
4. **发布工程**：签名、版本号、覆盖安装、更新策略、崩溃日志。
5. **降级设计**：低端机自动降 DPR、降帧、关粒子，而不是让玩家自己忍。

### 拿本项目练什么

**练习 10：做可重放对局**

- 要求：记录种子 + 每帧指令；用 Node 跑无渲染仿真；每 60 帧输出一次状态哈希。
- 验收：同一份录像跑两遍，哈希完全一致；改一个浮点运算后，能定位到第一个分叉帧。
- 参考：第 15 章。

**练习 11：写一个脚本 AI**

- 要求：不做机器学习，就做"每 5 秒检查一次资源，够 50 谷就造农人，够 3 个兵就进攻"。
- 验收：AI 能在一局里完成采集、造兵、进攻三个动作，不会卡住。
- 参考：第 09、15 章。

**练习 12：做一次真机性能剖析**

- 要求：用 Chrome Remote DevTools 的 Performance 面板录 10 秒，指出最耗时的三个函数。
- 验收：你能说出"这 10 秒里，渲染占 X ms、仿真占 Y ms、GC 占 Z ms"，并据此做一个优化，帧率提升 ≥ 10%。
- 参考：第 12 章。

**练习 13：发一个 release 包并覆盖升级**

- 要求：自己的 keystore、`versionCode` 递增、`assembleRelease`、装到已装旧版的手机上。
- 验收：新包能覆盖安装，旧数据不丢；换一台没装过的手机也能装。
- 参考：第 14 章。

### 怎么算过关

- [ ] 回放两次哈希一致。
- [ ] 目标机型 200 单位 ≥ 30fps，或你明确写下"本作上限 120 单位"并据此设计。
- [ ] 连续玩 30 分钟不崩、不烫到降频失控。
- [ ] release 包能覆盖升级，签名和密码有离线备份。
- [ ] 平衡表改一个数，能说清它会影响哪条曲线。

### 估算

- **2-3 个月**，而且大部分时间不是"学"，是"调"。
- 如果你只是想自己玩，精通档可以只做练习 10 和 12；发布和平衡是给"要给别人玩"准备的。

## 不要跳档

最常见的失败方式是：入门档还没打完 APK，就开始写寻路和战斗，三个月后有一堆桌面能跑、手机没装过的代码。

**每一档的最后一个练习都是"装到手机上验一次"。** 没过这一关，不要进下一档。
