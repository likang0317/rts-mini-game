# RTS 开发讲义

## 这套文档是什么

把仓库里这个 Phaser 3 + TypeScript 的 RTS 骨架，一步步推到"手机 APK 上能玩一局"。

不是游戏开发科普，也不是 API 手册。每一章讲三件事：**为什么这么做、这个仓库现在哪里不对、你动手时会踩什么坑。** 涉及代码的地方，都指到真实文件和行号；涉及数字的地方，标清楚是文档给的、我算的，还是经验值。

读者画像：熟悉 Vue / 前端工程，没做过游戏，目标是自己做一个能在安卓手机上装的 RTS。

## 阅读约定

- **`代码引用`**：括注文件名与行号，例如 `MainScene.ts:246-264`。行号以当前仓库为准，重构后会漂。
- **"经验值"**：没有权威来源、来自实践的数字，你可以改。
- **"推测"**：我的判断，没有验证过，需要你实测。
- **"文档"**：指 `docs/DESIGN-v2.md`。它和代码不一致的地方，我会直接指出来，不会替你圆。

## 和仓库里其他文档的关系

- `docs/DESIGN-v2.md`：玩法与数值设计。**它是设计意图，不是实现现状。**
- `docs/ui/UI-SPEC.md` + `docs/ui/ui-a.html`：桌面尺寸的 UI 视觉稿，主要用作配色与风格参考。
- `docs/ERA_RESEARCH.md`：时代考据，和工程实现无关。
- `docs/design/`：另一组偏 UI 设计视角的三章（工具链、信息与可读性、触屏与适配），和第 04、11 章互补，可作为延伸阅读。它是独立目录，编号不要和本讲义混用。
- 本目录：怎么把上面这些变成能装在手机上的东西。

## 一句话

**先出包，再分层，然后才是玩法。** 顺序对了，每一步都有可验证的产物；顺序错了，就是在桌面上做一个手机上不成立的游戏。
